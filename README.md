\# CareerPilotAI 🚀



AI-Powered Career Guidance Platform that helps students and job seekers improve their career preparation using Artificial Intelligence.



\## 📌 About the Project



CareerPilotAI is a full-stack web application designed to provide personalized career guidance and AI-powered career services.



The platform allows users to manage their career profile, upload resumes, analyze resumes, identify skill gaps, generate career roadmaps, and access several AI-powered career assistance tools.



\## ✨ Features



\- 🔐 User Registration \& Login

\- 🔑 JWT Authentication

\- 👤 Profile Management

\- 📄 Resume Upload

\- 🤖 AI Resume Analysis

\- 📊 ATS Score Analysis

\- 🎯 Skill Gap Analysis

\- 🗺️ Career Roadmap Generation

\- 💼 Job Matching

\- ✍️ Resume Improvement Suggestions

\- 📧 HR Email Generation

\- 💼 LinkedIn Summary Generation

\- 📝 Cover Letter Generation

\- 🎤 AI Interview Questions

\- 🔒 Protected Routes
